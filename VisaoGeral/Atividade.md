# 📚 Atividade Prática (2º Tempo)

---

## 👥 1. Quem utilizará o sistema?

- 👔 **Secretários da escola**
- 👨‍🏫 **Professores**
- 🛡️ **Administradores**

---

## ⚙️ 2. Requisitos Funcionais
> *O que o sistema deve fazer*

1. **Gestão de Alunos:** Cadastrar, editar e excluir alunos.
2. **Frequência:** Registrar a frequência dos alunos.
3. **Relatórios:** Consultar e emitir relatórios com os dados dos alunos.

---

## 🔒 3. Requisitos Não Funcionais
> *Como o sistema deve funcionar*

* 🎨 **Usabilidade:** O sistema deve ser fácil de usar, com uma interface simples e intuitiva.
* 🛡️ **Segurança:** O sistema deve proteger os dados dos alunos por meio de login e senha.

---

## 🎯 4. Por que levantar requisitos antes de desenvolver um software?

> É importante levantar os requisitos antes do desenvolvimento para entender as necessidades dos usuários, evitar erros e retrabalho, além de garantir que o sistema atenda aos objetivos do projeto.
